# Sources and attribution

The repository publishes original agent instructions and small helpers, not repackaged app installers or proprietary TV firmware.

- [CleanYourTV](https://github.com/Gathin23/cleanyourtv), Gathin23 and contributors. Original setup pinned `6ffa7fa5df7c38714cd89fd77fe636c53e759083`. Build, disable, restore, privacy and theme tools are fetched from upstream when needed; their source is not vendored here.
- [Lampa Android](https://github.com/lampa-app/LAMPA), historical release `v1.13.5`; [web frontend](https://github.com/yumata/lampa).
- [TorrServe](https://github.com/YouROK/TorrServe) and [TorrServer](https://github.com/YouROK/TorrServer), YouROK and contributors. Use the [F-Droid build](https://f-droid.org/en/packages/ru.yourok.torrserve/) for the FOSS Android client; historical client 143 with engine MatriX.147.1.
- [Just Player](https://github.com/moneytoo/Player), moneytoo and contributors, historical release `v0.217`.
- [androidtvremote2](https://github.com/tronikos/androidtvremote2), tronikos and contributors. The generic remote helper uses its API; historical working library `0.3.2`.
- [SmartTube](https://github.com/yuliskov/SmartTube), optional YouTube client, historical stable `32.68`.

Consult each upstream repository/distribution for its current license, release notes, signing certificate and support policy. Original hashes are reproducibility anchors, not recommendations to ignore later security fixes.

`tv-toolkit/tv-cleanyourtv-launcher/assets/cyberpunk/wallpaper.jpg` is the generated static artwork from the original setup, not a photograph of a user's home or a device screenshot. The accompanying prompt describes how it was made. Theme settings and package names are configuration examples; they do not include upstream application code.
